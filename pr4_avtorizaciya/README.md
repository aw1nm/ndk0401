# ПР4 — Авторизация (десктоп)

Десктопное окно входа на Python (tkinter): логин, пароль, показ пароля,
ограничение попыток (3), хеширование пароля SHA-256.

## Запуск
```
python autorize.py
```
Тестовые учётные данные: `admin` / `1234`, `user` / `qwerty`.
Tkinter входит в стандартную поставку Python для Windows — ничего ставить не нужно.
